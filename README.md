## Getting Started

1. Copy `env.example.txt` to `.env` and fill in your API credentials:
   ```bash
   cp env.example.txt .env
   ```

2. Configure your API key in `.env`:
   - `CREATEAI_API_KEY`: Your CreateAI API key
   - `CREATEAI_API_ENDPOINT`: API endpoint URL

3. Review the Product Requirements Document:
   - See `prd.md` for complete project specifications

4. Review the API Documentation:
   - See `API_DOCUMENTATION.md` for details on using the CreateAI API
